# MILTHA — miltha.org

A free site for studying the Bible in its earliest languages: Hebrew, Greek and Aramaic, with the
King James Version, Young's Literal Translation, the Septuagint, the Peshitta and the early Church Fathers.
*Miltha* (ܡܸܠܬ݂ܵܐ) is the Aramaic word for "the Word" in John 1:1.

The site is plain HTML pages plus a few Netlify Functions. There is no build step: Netlify publishes
the repository as it is and deploys `main` automatically. Every pull request gets a preview at
`deploy-preview-<n>--dreamy-puffpuff-7f52f3.netlify.app`.

## Pages

| Page | What it is |
|---|---|
| `index.html` | Home page |
| `bible.html` | Bible reader: KJV, YLT, Hebrew, Greek (TR), Peshitta, Septuagint; verse panel with other texts, Church Fathers, save/note |
| `study.html` | Word by Word: every Hebrew and Greek word (New Testament, Hebrew Old Testament, Septuagint) with dictionary entry and grammar |
| `daily.html` | Daily Word: a passage for every day of the year |
| `knowledge.html` | Knowledge Engine: questions answered from the site's own texts |
| `library.html` | The Church Fathers: 51 complete works |
| `history.html` | History and archaeology |
| `community.html` | Members' reflections on passages (moderated) |
| `account.html` | My Account: saved verses, notes, Daily Word reading, my posts |
| `moderate.html` | Moderators approve or hide posts and replies |
| `contribute.html` | How to support the site |

Shared files: `css/miltha.css`, `js/miltha.js` (menu, toasts), `js/account.js` (sign-in and member tools),
`js/bible-data.js` (book lists, manuscript notes, places), `js/wbw-data.js` (hand-written John 1:1 notes).

## Server (Netlify Functions)

| Path | File | Does |
|---|---|---|
| `/api/ask` | `netlify/functions/ask.mjs` | Knowledge Engine: finds passages in the Bible and the Library, then asks Claude |
| `/api/member` | `netlify/functions/member.mjs` | A member's saved verses, notes and Daily Word reading |
| `/api/posts` | `netlify/functions/posts.mjs` | Community posts and replies |
| `/api/moderate` | `netlify/functions/moderate.mjs` | Approve / hide posts (moderators only) |

Shared code is in `netlify/lib/` (sign-in check, posts, Bible reference parsing).
Member data and posts are kept in Netlify Blobs; sign-in is Netlify Identity (email + password).

Settings (Netlify → Environment variables):
- `MILTHA_ADMINS` — moderators' email addresses, comma separated.
- `ANTHROPIC_API_KEY`, `ANTHROPIC_BASE_URL` — supplied by Netlify's AI Gateway; `ANTHROPIC_MODEL` is optional.

## Data and how it is built

Everything in `data/` is generated by the scripts in `tools/` (Python 3). Run them in this order:

1. `tools/build_bible.py` → `data/bible/` (KJV, YLT, Hebrew, Greek, Peshitta NT)
2. `tools/build_words.py` → `data/words/`, `data/lexicon/`, and the accented Greek in `data/bible/gk`
3. `tools/build_lxx.py` → `data/bible/lxx/` (Septuagint) and `tools/build_peshitta_ot.py` → Peshitta Old Testament
4. `tools/build_daily.py` → `data/daily/plan.json` (from `tools/daily_plan.txt`)
5. `tools/build_lxx_words.py` → `data/words-lxx/` (Septuagint word by word; after step 2, as it adds to `data/lexicon/`)
6. `tools/build_library.py` → `data/library/` and `data/fathers-refs/`
7. `tools/build_search.py` → `data/search/` (the Knowledge Engine's search files)

Each script's opening comment says which source files it needs.
