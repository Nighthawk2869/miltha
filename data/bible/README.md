# Bible text data

Generated by `tools/build_bible.py` from the JSON files in
github.com/scrollmapper/bible_databases (MIT licence; underlying texts are public domain).

| Folder | Text | Books |
|---|---|---|
| `kjv` | King James Version (1769 standard text) | 66 |
| `ylt` | Young's Literal Translation (1898) | 66 |
| `heb` | Hebrew, Westminster Leningrad Codex | 39 (OT) |
| `gk`  | Greek Textus Receptus (1550/1894), unaccented | 27 (NT) |
| `ara` | Syriac Peshitta, unpointed | 27 (NT) |

Each file is an array of chapters; each chapter is an array of verse strings.
`index.json` holds verse counts per chapter for each text.
